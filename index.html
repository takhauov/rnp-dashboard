Импорт из отчёта Ozon «Начисления» (.xlsx)

Путь к файлу в личном кабинете: Финансы → Экономика магазина → Отчёт по начислениям, период 1 день.
Файл разносится по дням автоматически: Продажа, Вознаграждение, Логистика, Хранение, Прочее и Реклама берутся из соответствующих типов начисления, товары сопоставляются по SKU (укажите SKU в карточке товара во вкладке «Товары»). Если Ozon переименует или добавит новый тип начисления, дашборд сам спросит, куда его отнести, и запомнит выбор на будущее.

Импорт из отчёта WB «Продажи» (.xlsx)

Путь к файлу в личном кабинете: Аналитика → Отчёты → Продажи, период 1 день.
Из файла берётся только количество «Выкупили, шт.» по каждому артикулу — оно суммируется по всем складам за день и подставляется в строки товаров (себестоимость проданного считается от этого количества, как на Ozon). Товары сопоставляются по полю «Артикул WB» в карточке товара во вкладке «Товары». Остальные показатели (продажа, логистика, штрафы и т.д.) заполняются вручную. Отчёт должен быть за один день.

Итоги за месяц

Каталог товаров

Общий для всех разделов, где считается себестоимость (Ozon SEKAI, Ozon MELD, WB SEKAI, Сайт) — товар и его себестоимость вводятся один раз, а не отдельно на каждой площадке. Себестоимость может меняться от закупки к закупке: при изменении расчёт пересчитывается с указанной даты — все дни до неё считаются по старой себестоимости, все дни от неё и позже — по новой. Для сопоставления с выгрузками при импорте у каждого товара свой артикул на каждой площадке (задаются отдельно ниже).

Расходы вне МП — импорт из ДДС

Импорт ДДС — расходы разносятся сразу по всем разделам, в группу «Вне площадки». Строки, помеченные «Переносим в РНП? — Нет», в импорт не попадают. Если в файле встретится статья или направление, для которых ещё нет правила — дашборд один раз спросит, куда их отнести, и запомнит выбор навсегда.

Справка

Как устроен дашборд и что означают показатели. Одинакова для всех разделов. Обновляется вместе с изменением логики.

Разделы

Переключатель наверху («OZON SEKAI», «OZON MELD», «WB SEKAI», «ЯМ SEKAI», «ЯМ MELD», «Сайт») — это полностью независимые наборы данных: свои товары, свои дни, своя ставка налога.

Товары и себестоимость

Есть на Ozon, WB и «Сайте» — там себестоимость проданного считается по количеству и датированной себестоимости товара. У ЯМ товарного каталога нет: себестоимость проданного вводится вручную одной суммой за день. Себестоимость товара можно скорректировать с указанием даты — все дни ДО этой даты считаются по старой себестоимости, все дни ОТ неё и позже — по новой.

Ставка налога

Задаётся на вкладке «Ежедневные данные», действует так же, как себестоимость — с даты сохранения.

Ежедневные данные

Таблица заполняется по дням — при выборе месяца дни создаются автоматически. Tab/Shift+Tab внутри таблицы переходит на соседнюю строку того же дня (вниз/вверх), а не на соседний день. Если в ячейке было «0» — при клике оно сразу очищается, а если ничего не ввести и уйти с поля — вернётся обратно к «0».

Импорт (Ozon)

На вкладке «Ежедневные данные» — загрузка отчёта Ozon «Начисления» (.xlsx).
Путь к файлу: Финансы → Экономика магазина → Отчёт по начислениям, период 1 день.
Продажа, Вознаграждение, Логистика, Хранение, Прочее и Реклама разносятся по дням автоматически, товары сопоставляются по SKU (указывается в карточке товара). Если Ozon переименует или добавит новый тип начисления — дашборд остановит импорт, спросит, в какое поле его отнести, и запомнит выбор.

Импорт (WB)

Загружается отчёт WB «Продажи».
Путь к файлу: Аналитика → Отчёты → Продажи, период 1 день.
Из файла берётся только «Выкупили, шт.» по каждому артикулу (суммируется по всем складам), дата — из заголовка файла. Товары сопоставляются по полю «Артикул WB» в карточке товара. Отчёт должен быть за один день — за более длинный период построчных дат нет, импорт не сработает.

Импорт расходов вне МП (ДДС)

Кнопка «Расходы вне МП» на уровне дашборда (рядом с «Товары») — один файл выгрузки ДДС разносит расходы группы «Вне площадки» (ФОТ, внешняя логистика, сервисы/ПО и т.п.) сразу по всем разделам, без ручного ввода по каждому разделу отдельно.
Берутся только строки-расходы с заполненным направлением и без пометки «Переносим в РНП? — нет» (строки с выручкой, закупкой товара и налогом УСН исключены — они уже учитываются другими механизмами дашборда). Статья расхода определяет поле («ФОТ», «Внешняя логистика» и т.д.), направление — раздел (вб/озон/ям/сайт → конкретный WB/Ozon/ЯМ SEKAI или MELD, сайт).
Если статья или направление ещё не встречались — дашборд один раз спросит, куда их отнести, и запомнит выбор навсегда (сопоставления общие на весь дашборд, не по разделам). Из встроенных допущений: «Кредиты» (тело кредита) относится к «Прочие», «социальные налоги» — к «Налоги с ФОТ» — если это не так, поправить можно вручную (значение всё равно попадёт в раздел как конфликт с уже введённым, если там что-то было, либо примените и потом скорректируйте нужный день руками).
Если в конкретный день на конкретном поле уже есть ненулевое значение (ручной ввод или прошлый импорт) — дашборд не перезаписывает его молча, а показывает как конфликт и даёт выбрать: оставить старое или заменить суммой из файла.

Показатели в «Итоги / P&L»

Продажа → Доход на р/с (за вычетом расходов внутри площадки) → Маржа (минус себестоимость и самовыкупы) → Операционная прибыль, EBITDA (минус налог) → Чистая прибыль (минус расходы за пределами площадки: фулфилмент, ФОТ, аренда и т.п.).
